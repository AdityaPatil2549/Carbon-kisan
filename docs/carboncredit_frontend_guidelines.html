CarbonCredit.in — Design System

Frontend Design
Guidelines

A complete visual and interaction specification for the CarbonCredit micro-marketplace — a platform that connects rural Indian farmers with urban CSR buyers through verifiable carbon credits.

Environment-first palette Bilingual / multilingual Mobile-first design
✦

Design Philosophy

CarbonCredit.in serves two very different audiences — rural Indian farmers (often first-time app users, low digital literacy, mobile-only, regional language) and urban CSR professionals (desktop-first, data-driven, formal). The design must feel trustworthy and serious enough for a financial product while remaining approachable and clear for a farmer in Vidarbha.

🌱

Earth, not tech

Colors come from the forest floor, not a Silicon Valley palette. Dark forest greens, leaf accents, soil tones — the product should feel like it belongs to the land it serves.

🤝

Trust through clarity

Every number on screen is a farmer's income or a buyer's carbon commitment. Legibility, precision, and honesty in UI copy are non-negotiable.

🌐

Language-first

The farmer portal must work in Marathi, Hindi, Punjabi, Telugu, and Kannada. Layouts must not break with longer regional text. Language toggle is always visible.

Color Usage Rules

🌿 Leaf Green (#2ECC71) — reserve it
Use only for: primary CTA buttons, positive values (₹ earned, kg CO₂), active nav items, success badges, and interactive accents. Never use for decorative backgrounds or body text.
🌊 Deep Sky (#1A6B8A) — buyer identity
Use for the CSR buyer portal's primary CTA ("I'm a CSR buyer" button, buyer-side accents). This separates the two user journeys visually.
⚡ Harvest Gold (#F59E0B) — status only
Use only for "pending" badges, warnings, and OTP timers. Never as a decorative element.

02

Typography

A clean, legible system. No serif — farmers need maximum clarity on small screens. Weights are limited to 400 (body), 500 (UI labels), 600 (section headers), 700 (display/values). The number display style is especially important — farmers will read their ₹ earnings at a glance.

Font Stack

/* Primary — system stack ensures OS-native rendering in all languages */ font-family: 'Inter', 'Noto Sans', system-ui, -apple-system, sans-serif; /* For Hindi / Marathi / regional scripts */ font-family: 'Noto Sans Devanagari', 'Noto Sans', system-ui, sans-serif; /* For Punjabi (Gurmukhi) */ font-family: 'Noto Sans Gurmukhi', 'Noto Sans', system-ui, sans-serif; /* For Telugu / Kannada — same Noto family */ font-family: 'Noto Sans Telugu', 'Noto Sans', system-ui, sans-serif;
Noto Sans — the multilingual backbone
Load Noto Sans from Google Fonts with the correct subsets. The body font should auto-switch subset when the user changes language — no layout shift because Noto's metrics are consistent.

Remove the stats row (farmers onboarded, CO₂, income). These are not yet meaningful before user trust is established and may feel like vanity metrics to a first-time visitor. The two CTAs should be the only action on the page.

Page: Log Practice

URL: /farmer/log-practice  |  No design changes from the mockup. Implementation notes below.

Live result panel
The right panel (Estimated result) must update in real-time as the user changes dropdowns and sliders — without requiring them to click "Estimate carbon" first. The button confirms and locks the result for credit issuance.
Model attribution
Always show "Model: XGBoost · ICRISAT soil data · R² 0.81" under the result. This builds trust with a data-aware user and answers the "how does this number come from?" question before a judge or buyer asks.
Bilingual dropdowns
Every option in Crop type and Practice type must show both English and the local language name, separated by a slash. The form label should also be bilingual. See Language Switcher section for the full approach.
💡 Suggested innovation: practice photo AI hint
When a farmer uploads a photo of their field, run a lightweight image classifier (can be a pre-trained MobileNet on "no-till" vs "tilled" vs "cover crop" visual patterns) to auto-suggest the practice type. Show it as a suggestion chip below the upload zone: "We think this looks like no-till farming. Is that right?" — one tap to confirm. Reduces form friction significantly for farmers with lower literacy.

Suggested Innovations

Beyond the specified screens — these additions increase interactivity, reduce friction, and could make the product stand out in the hackathon and in real use.

🌾 Farmer Portal — Voice input for practice logging
Many Indian farmers are comfortable speaking but not typing. Add a microphone button to the Log Practice form. Use the Web Speech API (with Devanagari/regional language support) so a farmer can say "गेहूँ, बिना जुताई, पांच एकड़" and have it auto-fill the form fields. Label it "Voice fill (बोलकर भरें)".
📊 Farmer Portal — "What can I earn?" estimator on landing
On the farmer landing page, before login, add a simple 3-field estimator: [land size] + [crop] + [practice] → shows estimated ₹ income per season. No login required. This is the single most powerful conversion tool for farmer onboarding. Shows the value before asking for any commitment.
🏆 Farmer Portal — Community leaderboard (optional, opt-in)
Show a "Top farmers this month" mini-widget on the dashboard — first name + state + CO₂ kg. Opt-in only. Creates a community feeling and social proof. This is especially effective in FPO-aggregated onboarding where farmers know each other.
🌍 Buyer Portal — Impact certificate auto-generator
When a buyer purchases credits, auto-generate a branded PDF certificate in the background. Show a preview in the dashboard and a one-click download. The certificate should include: company name, total tCO₂e offset, number of farmers supported, region map, and the CarbonCredit.in verification QR code. CSR teams will use this directly in annual reports — extremely high value for the buyer.
🔔 Farmer Portal — WhatsApp notifications
When a farmer's credit is sold, send a WhatsApp Business API message in their preferred language: "आपका क्रेडिट CC-7821 Tata Motors ने ₹560 में खरीदा। 24 घंटे में UPI पेमेंट आएगा।" This is infinitely more effective than an in-app notification for a farmer who opens the app once a week.
📈 Buyer Portal — "Price trend" sparkline on each listing
On each credit listing card, show a tiny 7-day price sparkline for credits from that state/crop combination. Helps CSR buyers understand if prices are rising (buy now) or stable. One extra data point that adds significant perceived value for a data-aware buyer.

Accessibility

Minimum standards

✓ All interactive elements keyboard-navigable (Tab order)
✓ Focus rings visible (3px leaf-green outline, not removed)
✓ Color contrast: text on surface-2 meets AA (4.5:1)
✓ Leaf green #2ECC71 on ink (#0D1F15) = 7.3:1 — AAA
✓ All icons have aria-label
✓ OTP boxes labeled for screen readers
✓ Images have alt text
✓ Error states announced via aria-live="polite"

Farmer-specific accessibility

✓ Touch targets minimum 44×44px on mobile
✓ Font size never below 14px on farmer portal
✓ Button labels always include icon + text (never icon-only)
✓ No time-limited actions except OTP (always offer extend)
✓ Error messages in the user's selected language
✓ "What document do I need?" help tooltips on all verification fields
✓ Crop/practice dropdowns scroll-searchable
